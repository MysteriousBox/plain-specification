# plain-specification 开发文档

## 一、项目结构

- plain-specification-core：核心规范与表达式、基础接口、通用模型
- plain-specification-executor：执行器扩展（如 mybatis-plus、redis 等）
  - mybatis-plus：MyBatis-Plus 适配实现
  - redis：Redis 适配实现

## 二、核心接口与设计

- IBaseRepository<T, TID>：通用仓储接口，定义增删改查、异步操作等方法
- IReadBaseRepository<T, TID>：只读仓储接口，定义只读查询相关方法
- ISpecification<T>：规范接口，支持表达式组合、条件过滤、排序等
- IPageResult<T>：分页结果接口，统一分页返回结构
- PageQuery：分页参数对象
- OrderTypeEnum：排序类型枚举

## 三、依赖与技术栈

- JDK 8+
- Spring Data Redis、MyBatis-Plus
- Lombok、MapStruct
- JUnit 5、Mockito
- SLF4J、commons-lang3

## 四、代码风格与规范（强制遵循 Alibaba Java 开发手册）

1. **命名规范**：
   - 类名、接口名使用大驼峰，方法名、变量名小驼峰
   - 包名全小写，使用单数
   - 常量全大写，单词间下划线分隔
2. **注释规范**：
   - 所有类、接口、方法、字段必须有 Javadoc 注释，包含作者（@author）、版本（@since）、参数、返回值、异常等
   - 重要实现、复杂逻辑需有行内注释
3. **代码格式**：
   - if/for/while/else 等语句必须加大括号
   - 每行不超过 120 字符，适当换行
   - import 顺序：标准库、第三方、项目自有
4. **异常处理**：
   - 明确抛出/捕获异常，异常信息详实
   - 禁止空 catch，禁止无意义的异常包装
5. **日志规范**：
   - 统一使用 SLF4J，重要操作、异常需日志记录
6. **测试规范**：
   - 单元测试、集成测试需覆盖核心逻辑和边界场景
   - 测试类与被测类包结构一致，命名以 Test 结尾
7. **配置与扩展**：
   - 所有可变参数（如 batchSize、ttl、线程池等）均需可配置化，禁止硬编码
   - 支持通过构造器、配置类、Spring 注入等方式传递
8. **通用约定**：
   - 泛型使用需加类型边界说明
   - 方法参数需非空校验，fail-fast
   - 代码需易于扩展和维护

## 五、模块扩展说明

- 执行器模块需实现核心接口，支持异步、批量、分页等能力
- 支持多种数据源适配（如 MyBatis-Plus、Redis），实现解耦
- 规范表达式支持链式组合、动态拼装

## 七、使用示例

#### 注入多个仓储实例

您可以在 Spring `@Configuration` 类中定义多个 `@Bean` 方法，以注册具有不同类型、键或配置的不同 `GenericRedisRepository` 实例。使用 bean 名称或 `@Qualifier` 进行注入。

```java
// java
package org.example.config;

import org.plain.specification.redis.GenericRedisRepository;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.core.StringRedisTemplate;

@Configuration
public class RedisRepoConfig {

    @Bean(name = "userRepo")
    public GenericRedisRepository<User, Long> userRepo(StringRedisTemplate template) {
        return new GenericRedisRepository<>(template, User.class, "zset:users");
    }

    @Bean(name = "orderRepo")
    public GenericRedisRepository<Order, String> orderRepo(StringRedisTemplate template) {
        return new GenericRedisRepository<>(template, Order.class, "zset:orders");
    }

    // 自定义配置示例
    @Bean(name = "productRepo")
    public GenericRedisRepository<Product, Long> productRepo(StringRedisTemplate template) {
        return new GenericRedisRepository<>(template,
                new RedisRepositoryConfig.Builder<Product, Long>()
                        .zSetKey("zset:products")
                        .serializer(DefaultStrategies.jacksonSerializer())
                        .deserializer(DefaultStrategies.jacksonDeserializer(Product.class))
                        .idExtractor(DefaultStrategies.reflectionIdExtractor(Product.class, null))
                        .scoreProvider(DefaultStrategies.defaultScoreProvider())
                        .ttlProvider(DefaultStrategies.defaultTtlProvider())
                        .build());
    }
}
```

- 使用 `@Autowired` 与 `@Qualifier` 或按 bean 名称注入特定实例。
- 确保不同的泛型类型和 `zSetKey` 值以实现独立的仓储。

#### 通过继承创建仓储实例

您也可以通过继承 `RedisBaseRepository` 来创建具体的仓储类，然后在 Spring 配置中注册它们。这种方式提供更强的类型安全和定制能力。

```java
// java
public class UserRepository extends RedisBaseRepository<User, Long> {
    public UserRepository(StringRedisTemplate template) {
        super(template, new RedisRepositoryConfig.Builder<User, Long>()
                .zSetKey("zset:users")
                .serializer(DefaultStrategies.jacksonSerializer())
                .deserializer(DefaultStrategies.jacksonDeserializer(User.class))
                .idExtractor(DefaultStrategies.reflectionIdExtractor(User.class, null))
                .scoreProvider(DefaultStrategies.defaultScoreProvider())
                .ttlProvider(DefaultStrategies.defaultTtlProvider())
                .build());
    }
}

public class OrderRepository extends RedisBaseRepository<Order, String> {
    public OrderRepository(StringRedisTemplate template) {
        super(template, new RedisRepositoryConfig.Builder<Order, String>()
                .zSetKey("zset:orders")
                .serializer(DefaultStrategies.jacksonSerializer())
                .deserializer(DefaultStrategies.jacksonDeserializer(Order.class))
                .idExtractor(DefaultStrategies.reflectionIdExtractor(Order.class, null))
                .scoreProvider(DefaultStrategies.defaultScoreProvider())
                .ttlProvider(DefaultStrategies.defaultTtlProvider())
                .build());
    }
}

// 在配置类中
@Configuration
public class RedisRepoConfig {

    @Bean
    public UserRepository userRepo(StringRedisTemplate template) {
        return new UserRepository(template);
    }

    @Bean
    public OrderRepository orderRepo(StringRedisTemplate template) {
        return new OrderRepository(template);
    }
}
```

- 继承允许添加特定业务逻辑或覆盖方法。
- 每个子类实例在 IoC 容器中独立注册。
